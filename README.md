A standalone GitHub-compatible git forge in one Python process: git smart HTTP (upload-pack v2, receive-pack v0), the REST v3 API, GraphQL v4 and MCP, all served from its own store with no UI, no outside service and no git binary.

## Run it

```sh
python3 main.py
```
